# Code of Conduct

## The short version

Be decent. Critique code, not people. Assume the person on the other side is
trying to help.

## Expected behaviour

- Give feedback on the change, with a reason and, where useful, a suggestion.
- Assume good faith when a pull request misses something. Most gaps are missing
  context, not carelessness.
- Respect a maintainer's decision to say no. Not every good idea belongs in
  this repository.
- Ask when something is unclear. Nobody here has memorised Stellar.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, publishing someone's
private information, or persistent disruption after being asked to stop.

Also unacceptable, and specific to how this project is funded: opening
low-effort pull requests to inflate a contribution count, submitting work
generated by a model that you have not read, tested and understood, using more
than one account to claim issues, or coordinating with others to approve each
other's low-quality work. Contributions are judged on whether they make the
software better.

## Reporting

Report a problem to the maintainer address on the repository profile, or use
GitHub's private reporting. Reports are handled confidentially. Consequences
range from a warning to a permanent ban, at the maintainers' discretion.
